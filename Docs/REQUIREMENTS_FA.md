| بند تکلیف | پیاده‌سازی در نسخهٔ تازه | بررسی روی سیستم کاربر |

| Dash با Shift | افزایش سرعت جهان و حالت Dash و بازیابی زمانی | سرعت و افکت و نوار آماده‌شدن |

| مانع زمینی و هوایی و آیتم امتیازی | GroundObstacle و AirObstacle و Coin | مشاهدهٔ هر سه نوع و تعامل با آن‌ها |
| ارث‌بری مشترک از Interactable | هر سه کلاس فرزند مستقیم Interactable هستند | باز کردن اسکریپت‌ها |
| Animator با Run و Jump و Hit و Death و Transition | شش حالت شامل چهار حالت الزامی و Idle و Dash | پنجرهٔ Animator در Play |
| بازخورد بصری کوتاه پس از آسیب | تغییر رنگ و چشمک شخصیت و ذرات و فلش کم‌رنگ | برخورد با مانع |
| Main Menu و Pause Menu مستقل | دو ریشهٔ UI جدا با دکمه‌های متفاوت | شروع و توقف و ادامه و بازگشت |

| گرافیک و انیمیشن و افکت جذاب برای Bonus | محیط نقاشی‌شده و شیت تازه و چرخهٔ دویدن و ذرات نور و Dash و تغییر دید دوربین | بررسی چشمی اجرای واقعی |

## تحویل خارج از پیاده‌سازی گیم‌پلی

| مورد خواسته‌شده | وضعیت |
| --- | --- |
| سورس Unity | داخل بسته قرار دارد |
| لینک مخزن واقعی Git | باید برای مخزن خود کاربر ثبت شود و لینک ساختگی وارد نشده است |
| استفاده از gitignore همراه تکلیف | فایل استاد در ورودی موجود نبود و یک نسخهٔ مناسب Unity قرار داده شد |
| بیلد اجرایی | ابزار ساخت آماده است و باید با Editor روی سیستم کاربر ساخته و اجرا شود |
| گزارش کوتاه با تصاویر خروجی | متن ساختار آماده است و MAKE_SUBMISSION گزارش HTML را با تصاویر واقعی F12 تولید می‌کند |
| قالب نام GD_Hw1_FirstName_LastName_StudentId | اسکریپت بسته‌بندی این قالب را رعایت می‌کند |
| ذکر همفکران و منابع | منابع کمک در CREDITS.md و گزارش تولیدشده ذکر می‌شوند |

وجود پیاده‌سازی در سورس به معنی تأیید اجرای آن در Unity نیست
